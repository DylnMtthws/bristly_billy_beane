Color filtering uses the combined identity of the deck's commander entries, never library cards; pair identity is the union. All filters compose before count/pagination. Unknown/no-commander decks must not be invented as colorless when filtering. Existing decks remain private unless their owner made them public.

Commander text supports case-insensitive name search and bounded local suggestions. Reuse current Partner, Partner with, Friends forever, Background and Doctor companion handling; do not invent new card rules or use substring 'partner' heuristics. Preserve partial primary-name searching without requiring a selection.

All routes require existing signed-in Research gate, private/no-store. No external requests.

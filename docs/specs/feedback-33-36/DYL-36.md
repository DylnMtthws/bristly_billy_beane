# DYL-36 — Paste plain-text deck import
Add Import deck beside New deck in Library, usable desktop/mobile/keyboard. Show title and multiline decklist input, parse/preview and explicit confirmation to create a new private editable deck. Do not mutate existing decks. Use imported local card corpus only; no Moxfield/Archidekt API or URL fetching.
Support common text exports: `1 Card Name`, `1x Card Name`, optional `(SET) collector` and `*F*`/foil tags, blank lines, comments, Commander/Commanders, Deck/Mainboard and Sideboard/Maybeboard sections; Archidekt category annotations such as `[Commander{top}]` and ordinary type tags. Normalize names and match exact names/known face names without guessing ambiguous matches. Aggregate quantities safely. Preserve non-mainboard cards in appropriate non-library zones. Reject unknown/ambiguous names with line-level actionable errors rather than silently dropping cards. Report non-Commander-legal cards clearly; never silently import a truncated deck.
Commander sections/tags nominate commanders. If absent, allow explicit commander selection from eligible parsed cards; never assume first legendary creature is commander. Validate actual compatible partner/background pairs using existing helpers and ensure each nominated card is removed from library quantity exactly once. Allow incomplete decks with existing validation shown, but no illegal commander pairing or malformed/oversized input. Bound request size/line count/quantity and reject negatives/zero/huge counts. Preview must make no DB changes; final submission revalidates server-side and atomically creates deck/zones/entries with owner ID from session, private visibility and no published share. Preserve entered text/errors on validation failure. CSRF/auth/ownership apply. Add parser, route and persistence tests covering successful formats, missing commander selection, ambiguity/unresolved card, pair validity, quantity and rollback. Prefer a separate deck_text_import.py module and narrow repository entry point.
Own import code, Library dialog/template/JS only; another session owns playmats in builder routes/deck_documents/schema.

Coordinator review clarifications: Sideboard/Maybeboard never contribute to the main library's 100-card count or color/singleton validation. Preserve full double-face names containing ` // `. Reject non-Commander-legal imported cards with line errors (matching existing new-card legality constraints), so the user can correct the list without any silent truncation. Explicit commander lines must have one copy; moving a commander selected from an untagged list transfers exactly one copy from its original zone. Preview and persisted quantities must agree.
